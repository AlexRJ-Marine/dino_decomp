# Feature status matrix

Status: **maintained index.** One row per retail feature or screen. This is the
feature view of the project; `notes/OPEN-TASKS.md` is the task view and
`notes/evidence-index.md` is the claim view.

Status vocabulary:

- **ported** — the feature runs in the portable viewer against retail data and
  has a test.
- **partial** — the main flow works; the listed gaps remain.
- **decoded** — retail data/behaviour is solved and documented, but not ported.
- **not ported** — neither decoded nor implemented.

The **Screen** and **Controls** columns are retail 800x600 control-map ids
(`ui-coordinates.md`); query them with `tools/formats/ui_map.py find`. The
row is validated by `tests/test_feature_matrix.py`: links must resolve, screen
ids and control names must exist in `ui-coordinates.json`, and every listed
test must exist.
